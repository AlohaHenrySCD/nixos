# 任务委派与上下文管理

- 主对话聚焦于架构设计、方案权衡、关键决策与最终复核，避免被长输出或机械操作污染上下文。
- 对于耗时较长、步骤繁琐或对增加项目整体理解有限的任务，主动委派给子代理/外部代理执行：
  - 大范围代码搜索、多文件调研、跨平台对比与只读排查：委派给原生 `research` 子代理（Gemini 4 Neon）。
  - 代码修改、重构、分条 Git commit 及命令/求值验证：通过 `delegate_task` 委派给 Codex（`providerInstanceId: "codex"`、`model: "gpt-6.2-astra"`、`options: { reasoningEffort: "high" }`）。
- 仅在主线程直接处理简短定向查询、直接问答、1–2 行极小修正以及最终汇总复核。
- 当自身作为被委派的子代理或子任务运行时，直接独立完成分配的工作，除非任务明确要求，不再二次委派。
