## Same key, different place · 同键不同用途

Desktop shortcuts are handled before terminal shortcuts; the foreground program receives the remaining keys. These are application-received keys; consult [keyd](keyd.md) when starting from a physical key.

| Key / 按键 | Context and effect |
| --- | --- |
| `Ctrl+R` | [Fish](fish.md#history-and-completion): fzf history; [ov](ov.md#change-wrapping-and-display): colored columns; [Helix](helix.md#editing): redo in normal/select mode |
| `Ctrl+U` | [Fish](fish.md#edit-the-command-line): delete to line start; [fzf](fzf.md#edit-the-query): delete query prefix; [ov](ov.md#move-through-output): half page up |
| `Ctrl+Shift+U` | [Kitty](kitty.md#review-terminal-output): scroll half a page up |
| `Alt+R` | [Kitty](kitty.md#review-terminal-output): Mitos scrollback; intercepted before terminal apps |
| `F1 / F2` | [Niri](niri.md#screenshots-and-session): screenshots; Fish help uses Alt+H instead |
| `Esc` | [Kitty](kitty.md#tools-and-sessions): deactivate Fcitx5 and send Esc to the application |
| `Ctrl+C` | [Fish](fish.md#edit-the-command-line): clear prompt; a running terminal program usually receives an interrupt; [Kitty copy](kitty.md#copy-and-paste) uses Ctrl+Shift+C |
| `q` | Leaves many viewers; [Yazi](yazi.md#useful-sequences) through Fish's `y` also changes Fish's directory; editors have their own quit actions |
