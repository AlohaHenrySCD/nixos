## Switch language and punctuation

| Shortcut | Use |
| --- | --- |
| `Ctrl+Shift+F12` | Toggle input method |
| `Zenkaku/Hankaku / Hangul` | Additional input-method toggle keys |
| `Hangul/Hanja / Hangul/Romaja` | Activate / deactivate input method |
| `Super+Space / Super+Shift+Space` | Next / previous input-method group |
| `Caps Lock` | Rime ASCII switching with composition cleared; generated by physical Left Alt |
| `Ctrl+Shift+P` | Toggle Chinese/English punctuation |
| `Ctrl+Shift+4 / Ctrl+Shift+$` | Toggle simplified/traditional conversion |
| `` F4 / Ctrl+` / Ctrl+Shift+` `` | Open Rime scheme/options menu |
| `Shift or Ctrl alone` | Does not switch Rime language mode |

While composing, ASCII punctuation/symbol keys first commit the raw typed text, then Rime handles the symbol using the selected Chinese/English punctuation and half/full-width settings: `nihao,` → `nihao,` or `nihao，`. The exceptions are `-` and `=` for paging, and `[` and `]` for character selection. Apostrophe and backtick now commit raw text instead of acting as Rime separators or spelling keys. Space and digits retain candidate selection.

## Choose candidates

Fcitx5 handles its own candidate keys before Rime. If Tab reaches Rime while composing, it moves by syllable instead; the next table shows that layer.

| Shortcut | Use |
| --- | --- |
| `Space` | Confirm candidate |
| `1…5` | Choose a candidate on the current page |
| `Tab / Shift+Tab` | Fcitx5 next / previous candidate |
| `Down / Up` | Fcitx5 next / previous candidate page |
| `= / -` | Rime next / previous page while candidate menu is open |
| `[ / ]` | Select the first / last character of a candidate |
| `Ctrl+Delete` | Delete the learned candidate |

## Edit the composition

| Shortcut | Use |
| --- | --- |
| `Left / Right` | Move one character without wrapping |
| `Shift+Left / Shift+Right` / `Alt+Left / Alt+Right` | Move one syllable |
| `Shift+Tab / Tab` | Previous / next syllable when passed to Rime |
| `Backspace` | Revert the preceding composition step |
| `Ctrl+Backspace` | Delete/revert the previous syllable |
| `Delete` | Delete at the composition cursor |
| `Esc` | Cancel composition |
| `Enter` | Commit raw typed input |
| `Ctrl+Enter` | Commit script text |
| `Ctrl+Shift+Enter` | Commit candidate comment |
| `Ctrl+Alt+P` | Toggle preedit display in the application |

## Use the numeric keypad

| Shortcut | Use |
| --- | --- |
| `Keypad 0…9` | Send the corresponding digit while composing |
| `Keypad . * + - /` | Send the corresponding punctuation while composing |
| `Keypad Enter` | Send Enter while composing |

## Useful sequences

| Shortcut | Use |
| --- | --- |
| `physical Backspace → pinyin → Tab → Space` | Activate input, choose a candidate and confirm |
| `pinyin → = → digit` | Page through candidates and choose one |
| `raw text → symbol` (except `-=[]`) | Commit the original letters; the symbol follows Rime's punctuation/width settings |
| `Ctrl+Shift+P → punctuation` | Change punctuation style |
| `F4 → choose an option` | Change a Rime option |
| `rq / sj / xq` | Offer date / time / weekday candidates |
| `rqen / rqzh / dt / ts` | Offer English date / Chinese date / date-time / timestamp |
| `Esc` in Kitty | Cancel/leave editor input and deactivate Fcitx5 |

Switching away from Rime commits raw input. Kitty reserves Ctrl+Shift+U for scrollback; Fcitx5 direct Unicode input on that key is disabled.
